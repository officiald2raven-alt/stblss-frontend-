# STBLSS — Standalone Source Bundle

This file contains the **complete, standalone source code** for STBLSS. It is a pure Vite + React + Tailwind CSS app that builds and runs anywhere with no backend, no database, and no accounts.

## How to use this bundle

1. Download this file.
2. Create a new folder for your GitHub repo.
3. Create each file below at the exact path shown under the `=== FILE: path ===` headers.
4. Run `npm install` then `npm run dev` to run locally, or `npm run build` to deploy.
5. Push to GitHub.

=== FILE: README.md ===

````markdown
# STBLSS

An open-source, fully stateless, non-custodial stablecoin payment terminal — built to kill transaction anxiety before you hit send.

STBLSS lets you generate anonymous stablecoin payment links and collect payments with an automated 99% recipient / 1% terminal fee split. There are no accounts, no server databases, and no tracking cookies. All transaction signing happens exclusively via your browser wallet.

## What it does

1. **Generate a link** — paste your 0x wallet address, pick a network and token, enter the amount (optional memo + due date). EIP-55 checksum validation hard-blocks recipient typos before a link can even be created.
2. **Share the link** — copy and send it to your payer through whatever channel you choose (email, DM, invoice, carrier pigeon).
3. **Collect anxiety-free** — the payer opens the link, sees the recipient address in plain text with a one-tap block-explorer verify, then pays from their own wallet. Two ERC-20 transfers: 99% to you, 1% terminal fee. STBLSS never holds funds and only flips to "complete" after the network confirms each leg on-chain.

STBLSS sends zero emails. You copy the link and send it yourself.

## What STBLSS does NOT do

- Does not hold, custody, or touch user funds at any point.
- Does not use accounts, passwords, or backend storage.
- Does not collect personal information, IP logs, or financial histories.
- Does not send emails or notifications.
- Is not a money transmitter — it is a client-side transaction composer UI.

All data lives entirely in the URL parameter text. The app compiles raw ERC-20 `transfer(address,uint256)` calls and hands them to your browser wallet to sign.

## Fee math (auditable)

```js
const fee = Math.round(total * 0.01 * 1e6) / 1e6;      // exactly 1% of the total
const payout = Math.round((total - fee) * 1e6) / 1e6;   // the remaining 99%
```

The platform fee wallet address is hardcoded in `src/lib/stblss.js` and visible in the source and on the checkout page.

## Supported networks

- Base (Layer 2)
- Arbitrum One (Layer 2)
- Ethereum Mainnet

## Supported tokens

- USDC
- USDT
````

```js
// PUBLIC, VERIFIABLE FEE MATH — anyone inspecting this file can audit the split.
// Total "Amount Due" is split into exactly two transfers and nothing goes anywhere else:
//   - 99%  → recipient's wallet (payout)
//   -  1%  → platform's hardcoded fee wallet (fee)
//   -  0%  → any other address
export function splitAmount(amount) {
  const total = Number(amount) || 0;        // the full Amount Due from the URL
  const fee = Math.round(total * 0.01 * 1e6) / 1e6;   // exactly 1% of the total
  const payout = Math.round((total - fee) * 1e6) / 1e6; // the remaining 99% (total − fee)
  return { total, fee, payout };
}

export function toUnits(amount, decimals) {
  const [whole, frac = ""] = String(amount).split(".");
  const padded = (frac + "0".repeat(decimals)).slice(0, decimals);
  return BigInt((whole || "0") + padded);
}

// ERC-20 transfer(address,uint256) calldata
export function encodeTransfer(to, units) {
  const addr = to.toLowerCase().replace("0x", "").padStart(64, "0");
  const amt = units.toString(16).padStart(64, "0");
  return "0xa9059cbb" + addr + amt;
}

export function formatAmount(value) {
  const n = Number(value);
  if (!isFinite(n)) return "0";
  return n.toLocaleString("en-US", { maximumFractionDigits: 6 });
}

export function shortAddress(addr = "") {
  if (addr.length < 14) return addr;
  return `${addr.slice(0, 8)}…${addr.slice(-6)}`;
}

// Strict format validation for an EVM address: must be 0x + exactly 40 hex chars.
// Catches the common paste/typing typos (wrong length, bad chars, missing prefix).
export function isEvmAddress(addr = "") {
  return /^0x[a-fA-F0-9]{40}$/.test(addr.trim());
}

// EIP-55 mixed-case checksum verification.
// Every EVM address carries a built-in checksum encoded in the casing of its
// hex letters. If a single character is mistyped (but still valid hex + length),
// the recomputed checksum won't match and we can flag it — pure math, no
// network calls, runs entirely in the browser. This is the strongest no-backend
// guard against recipient setup errors (the one hole format-validation alone
// cannot close). Uses `js-sha3` keccak256; all-lowercase or all-uppercase
// addresses have NO checksum encoded, so they are treated as "unverified" (null).
import { keccak_256 } from "js-sha3";
export function isChecksumValid(addr = "") {
  const raw = addr.trim();
  if (!/^0x[a-fA-F0-9]{40}$/.test(raw)) return false;
  // All-lowercase or all-uppercase = no checksum encoded → cannot verify.
  if (raw === raw.toLowerCase() || raw === raw.toUpperCase()) return null;
  const hex = raw.slice(2);
  const hash = keccak_256(hex.toLowerCase());
  let checksummed = "0x";
  for (let i = 0; i < hex.length; i++) {
    const c = hex[i];
    if (/[0-9]/.test(c)) {
      checksummed += c;
    } else {
      checksummed += parseInt(hash[i], 16) >= 8 ? c.toUpperCase() : c.toLowerCase();
    }
  }
  return checksummed === raw;
}

// Stateless on-chain "paid" check — reads the chosen network's public RPC
// directly from the browser and scans recent ERC-20 Transfer logs to the
// recipient for a transfer whose value matches the expected payout (the 99%
// amount that lands in the recipient's wallet). No backend, no indexer.
//
// Honest limitations (stateless tool + public RPC range limits):
//   - Only scans a recent block window, so a payment confirmed long ago may
//     not be found → "unpaid" means "not seen in the recent window", NOT
//     definitively "never paid".
//   - If the public RPC rejects the range or fails, returns "unknown".
export async function checkPaymentStatus(netKey, tokenAddress, recipient, expectedPayoutUnits) {
  const net = NETWORKS[netKey];
  if (!net || !net.evm || !tokenAddress || !recipient) return { status: "unknown" };
  const rpc = net.params.rpcUrls[0];
  const TRANSFER_TOPIC =
    "0xddf252ad1be2c89b69c2b068fc378daa952ba7f163c4a11628f55a4df523b4ef";
  const toTopic = "0x" + recipient.toLowerCase().replace(/^0x/, "").padStart(64, "0");

  const rpcCall = async (method, params) => {
    const res = await fetch(rpc, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ jsonrpc: "2.0", id: 1, method, params }),
    });
    const json = await res.json();
    if (json.error) throw new Error(json.error.message || "rpc error");
    return json.result;
  };

  try {
    const latest = BigInt(await rpcCall("eth_blockNumber", []));
    const WINDOW = 100000n; // ~1-2 days on L2s
    const fromBlock = latest > WINDOW ? "0x" + (latest - WINDOW).toString(16) : "0x0";
    const logs = await rpcCall("eth_getLogs", [{
      fromBlock,
      toBlock: "latest",
      address: tokenAddress,
      topics: [TRANSFER_TOPIC, null, toTopic],
    }]);
    const target = BigInt(expectedPayoutUnits);
    for (const log of logs || []) {
      if (!log.data) continue;
      if (BigInt(log.data) === target) return { status: "paid" };
    }
    return { status: "unpaid" };
  } catch (e) {
    return { status: "unknown", error: e?.message };
  }
}
```

```jsx
import React, { useState } from "react";
import { Loader2, Wallet, ShieldCheck } from "lucide-react";
import { NETWORKS, PLATFORM_FEE_WALLET, encodeTransfer, splitAmount, toUnits } from "@/lib/stblss";

// Poll a single transaction's receipt until mined; confirm success via status 0x1.
// Stateless: read through the payer's OWN wallet RPC (window.ethereum) — no backend.
async function awaitReceipt(eth, hash, { timeoutMs = 120000, intervalMs = 2500 } = {}) {
  const start = Date.now();
  while (Date.now() - start < timeoutMs) {
    let receipt = null;
    try {
      receipt = await eth.request({ method: "eth_getTransactionReceipt", params: [hash] });
    } catch { /* transient RPC — keep polling */ }
    if (receipt) return { confirmed: Number(receipt.status) === 1, receipt };
    await new Promise((r) => setTimeout(r, intervalMs));
  }
  return { confirmed: false, receipt: null };
}

// Poll an EIP-5792 batch (wallet_sendCalls) via wallet_getCallsStatus until the
// wallet reports CONFIRMED or FAILED. Verify per-call receipts when available.
async function awaitCallsStatus(eth, id, { timeoutMs = 120000, intervalMs = 2500 } = {}) {
  const start = Date.now();
  while (Date.now() - start < timeoutMs) {
    let res = null;
    try {
      res = await eth.request({ method: "wallet_getCallsStatus", params: [id] });
    } catch { /* transient — keep polling */ }
    if (res) {
      const status = String(res.status || "").toUpperCase();
      if (status === "CONFIRMED") {
        const receipts = Array.isArray(res.receipts) ? res.receipts : [];
        // If the wallet returned per-call receipts, verify each succeeded (0x1).
        // If it only returned CONFIRMED with no receipts, accept the wallet's word.
        return { confirmed: receipts.length ? receipts.every((r) => Number(r.status) === 1) : true };
      }
      if (status === "FAILED") return { confirmed: false };
    }
    await new Promise((r) => setTimeout(r, intervalMs));
  }
  return { confirmed: false };
}

// Wallet error codes meaning "the user declined the popup" — never auto-retry.
const USER_REJECTED = new Set([4001, -32001]);

export default function PayButton({ to, netKey, token, amount, onPaid }) {
  const [status, setStatus] = useState("idle"); // idle | working | confirming | paid
  const [error, setError] = useState("");
  const [flow, setFlow] = useState(null); // "batched" | "per-call" — shown for transparency

  const net = NETWORKS[netKey];

  const pay = async () => {
    setError("");
    const eth = window.ethereum;
    if (!net?.evm) {
      setError("Unsupported network. Open a valid STBLSS payment link and try again.");
      return;
    }
    if (!eth) {
      setError("No browser wallet detected. Install a wallet extension such as MetaMask to continue.");
      return;
    }

    setStatus("working");
    try {
      const accounts = await eth.request({ method: "eth_requestAccounts" });
      const from = accounts[0];

      try {
        await eth.request({ method: "wallet_switchEthereumChain", params: [{ chainId: net.chainIdHex }] });
      } catch (switchErr) {
        if (switchErr.code === 4902) {
          await eth.request({ method: "wallet_addEthereumChain", params: [net.params] });
        } else {
          throw switchErr;
        }
      }

      // --- NON-CUSTODIAL TRANSFER BUILD ---
      // We only compile raw ERC-20 `transfer(address,uint256)` payloads and hand them
      // to the user's LOCAL browser wallet (window.ethereum) to sign and broadcast.
      // No platform smart contract, relayer, or custodial layer is ever involved.
      const tokenInfo = net.tokens[token];
      const { fee, payout } = splitAmount(amount); // 99% payout, 1% fee, 0% elsewhere

      const calls = [
        { to: tokenInfo.address, data: encodeTransfer(to, toUnits(payout, tokenInfo.decimals)) },                 // 99% → recipient
        { to: tokenInfo.address, data: encodeTransfer(PLATFORM_FEE_WALLET, toUnits(fee, tokenInfo.decimals)) }, //  1% → fee wallet
      ];

      setStatus("confirming");

      let confirmed = false;
      let batchedAttempted = false;

      // --- PREFERRED: EIP-5792 batched send (ONE signature, verified on-chain) ---
      // The wallet signs both transfers at once; we then poll its calls-status
      // until CONFIRMED and check every receipt. Fully stateless — reads only
      // through the payer's own wallet RPC.
      // SAFETY: once we invoke wallet_sendCalls, if it throws a non-rejected
      // error we cannot know whether the wallet already submitted on-chain.
      // To prevent a double-send, we never fall through to per-call after a
      // batch has been attempted — except when the wallet clearly doesn't
      // support the method (method-not-found, code -32601).
      try {
        const callsId = await eth.request({
          method: "wallet_sendCalls",
          params: [{ version: "1.0", chainId: net.chainIdHex, from, calls }],
        });
        if (callsId) {
          batchedAttempted = true;
          setFlow("batched");
          const res = await awaitCallsStatus(eth, callsId);
          confirmed = res.confirmed;
        }
      } catch (batchErr) {
        // User declined the single-signature popup → stop, don't pester with a second.
        if (USER_REJECTED.has(batchErr?.code)) throw batchErr;
        if (batchErr?.code === -32601) {
          // Method not found — wallet doesn't support EIP-5792. Safe to fall back.
        } else {
          // Ambiguous: the wallet may have already submitted on-chain.
          // Do NOT fall through to per-call — that would double-send.
          setStatus("idle");
          setError("The batched payment couldn't be confirmed. Check your wallet or block explorer — no double charge was made.");
          return;
        }
      }

      // --- FALLBACK: per-call send (universal) + receipt verification ---
      // Every wallet supports this; we get a hash for each transfer and confirm
      // each against a mined receipt. Two approvals, but verified everywhere.
      // Only runs if batching was never submitted (no double-send after a batch).
      if (!confirmed && !batchedAttempted) {
        setFlow("per-call");
        const hashes = [];
        for (const call of calls) {
          const hash = await eth.request({ method: "eth_sendTransaction", params: [{ from, to: call.to, data: call.data }] });
          if (hash) hashes.push(hash);
        }
        let allOk = true;
        for (const hash of hashes) {
          const { confirmed: ok } = await awaitReceipt(eth, hash);
          if (!ok) { allOk = false; break; }
        }
        confirmed = allOk;
      }

      if (confirmed) {
        setStatus("paid");
        onPaid?.();
      } else {
        setStatus("idle");
        setError("A transfer did not confirm on-chain in time. Check your wallet or block explorer — your funds are safe and no custodial step was ever involved.");
      }
    } catch (e) {
      setStatus("idle");
      setError(e?.message || "Transaction was not completed.");
    }
  };

  const label =
    status === "working" ? "Awaiting Wallet Confirmation…" :
    status === "confirming" ? "Confirming on-chain…" :
    "Connect Wallet & Pay Now";

  return (
    <div>
      <button
        onClick={pay}
        disabled={status === "working" || status === "confirming"}
        className="flex w-full items-center justify-center gap-2 rounded-2xl bg-emerald-400 px-6 py-4 text-base font-bold text-slate-950 shadow-[0_0_40px_-12px_rgba(52,211,153,0.7)] transition-all duration-300 hover:bg-emerald-300 disabled:opacity-60"
      >
        {status === "working" || status === "confirming" ? <Loader2 className="h-5 w-5 animate-spin" /> : <Wallet className="h-5 w-5" />}
        {label}
      </button>
      {status === "confirming" && (
        <p className="mt-3 flex items-center justify-center gap-1.5 text-xs font-medium text-slate-400">
          <ShieldCheck className="h-4 w-4 text-emerald-400" />
          {flow === "batched"
            ? "Verifying your single batched payment on-chain — both transfers confirmed in one block."
            : "Verifying each transfer on-chain — every leg is confirmed, never assumed."}
        </p>
      )}
      {error && <p className="mt-3 text-sm text-rose-400">{error}</p>}
    </div>
  );
}
```

```jsx
  checking: { Icon: Loader2, text: "Verifying on-chain…", cls: "border-slate-700 bg-slate-800/40 text-slate-300", spin: true },
  paid: { Icon: CheckCircle2, text: "Paid · verified on-chain", cls: "border-emerald-400/50 bg-emerald-400/10 text-emerald-300", spin: false },
  unpaid: { Icon: Clock, text: "Not yet detected on-chain", cls: "border-slate-700 bg-slate-800/40 text-slate-400", spin: false },

};

export default function InvoiceStatus({ netKey, tokenAddress, recipient, expectedPayoutUnits }) {
  const [state, setState] = useState("checking");

  useEffect(() => {
    let active = true;
    setState("checking");
    checkPaymentStatus(netKey, tokenAddress, recipient, expectedPayoutUnits).then((r) => {
      if (active) setState(r.status);
    });
    return () => { active = false; };
  }, [netKey, tokenAddress, recipient, expectedPayoutUnits]);

  const { Icon, text, cls, spin } = CONFIG[state] || CONFIG.unknown;

  return (
    <div className={`mb-4 inline-flex items-center gap-2 rounded-full border px-3 py-1.5 text-xs font-semibold ${cls}`}>
      <Icon className={`h-3.5 w-3.5 ${spin ? "animate-spin" : ""}`} />
      {text}
    </div>
  );
}
```

```jsx
import React, { useState } from "react";
import { ShieldCheck, AlertTriangle, ClipboardPaste, Wallet, X } from "lucide-react";
import { isEvmAddress, isChecksumValid } from "@/lib/stblss";

// Recipient address entry — paste-only (no QR, no manual-typing risk).
// Users copy the address from their wallet app and paste it here. EIP-55
// checksum still guards any pasted value against single-character typos.
export default function RecipientAddressInput({ value, onChange }) {
  const addr = (value || "").trim();
  const addrValid = isEvmAddress(addr);
  const checksumBad = addrValid && isChecksumValid(addr) === false;

  const [connecting, setConnecting] = useState(false);
  const [notice, setNotice] = useState("");

  const pasteFromClipboard = async () => {
    try {
      const text = await navigator.clipboard.readText();
      if (text) onChange(text.trim());
    } catch {
      // Clipboard read blocked — paste manually into the field below.
    }
  };

  // Pull the active account straight from the browser wallet extension.
  // Prevents human setup typos by never typing the address at all.
  const connectAndAutofill = async () => {
    setNotice("");
    const eth = window.ethereum;
    // Regular mobile Chrome/Safari has no injected wallet — nothing would
    // happen silently. Give the user a clear, actionable message instead.
    if (!eth) {
      setNotice(
        "No wallet browser detected. Open this page inside your wallet app's built-in browser (MetaMask, Trust, Coinbase, etc.) to use Connect & Autofill, or copy your address from your wallet and paste it above."
      );
      return;
    }
    setConnecting(true);
    try {
      const accounts = await eth.request({ method: "eth_requestAccounts" });
      if (accounts?.[0]) {
        onChange(accounts[0]);
      } else {
        setNotice("Your wallet didn't return an account. Paste your address manually above.");
      }
    } catch {
      // user rejected the connection prompt — leave the field as-is
    } finally {
      setConnecting(false);
    }
  };

  const clear = () => onChange("");

  const border = !addr
    ? "border-slate-700 focus:border-emerald-400 focus:ring-emerald-400/20"
    : checksumBad
    ? "border-amber-500/70 focus:border-amber-500 focus:ring-amber-500/20"
    : addrValid
    ? "border-emerald-500/50 focus:border-emerald-500 focus:ring-emerald-500/20"
    : "border-rose-500/70 focus:border-rose-500 focus:ring-rose-500/20";

  return (
    <div className="rounded-2xl border border-slate-800 bg-slate-950/40 p-4">
      <p className="text-xs leading-relaxed text-slate-400">
        Safest: tap <span className="font-semibold text-slate-300">Connect &amp; Autofill</span> to pull your address
        straight from your wallet. Or copy it from your wallet and{" "}
        <span className="font-semibold text-slate-300">paste</span> it below — your address will be EIP-55
        checksum-verified to catch typos.
      </p>

      <div className="mt-3 flex gap-2">
        <input
          placeholder="Paste your 0x wallet address"
          value={value}
          onChange={(e) => onChange(e.target.value)}
          className={`flex-1 rounded-xl border bg-slate-900/60 px-4 py-3 font-mono text-sm text-slate-100 outline-none transition focus:ring-2 ${border}`}
        />
        {addr && (
          <button
            type="button"
            onClick={clear}
            aria-label="Clear address"
            className="inline-flex items-center justify-center rounded-xl border border-slate-700 bg-slate-800/60 px-3 text-slate-300 transition hover:border-slate-500 hover:bg-slate-800"
          >
            <X className="h-4 w-4" />
          </button>
        )}
      </div>

      <div className="mt-2 flex flex-wrap gap-2">
        <button
          type="button"
          onClick={connectAndAutofill}
          className="inline-flex items-center justify-center gap-2 rounded-xl border border-emerald-400/50 bg-emerald-400/10 px-4 py-2.5 text-sm font-bold text-emerald-300 transition hover:bg-emerald-400/20 disabled:opacity-60"
        >
          <Wallet className="h-4 w-4" /> {connecting ? "Connecting…" : "Connect & Autofill"}
        </button>
        <button
          type="button"
          onClick={pasteFromClipboard}
          className="inline-flex items-center justify-center gap-2 rounded-xl border border-slate-700 bg-slate-800/60 px-4 py-2.5 text-sm font-medium text-slate-200 transition hover:border-slate-500 hover:bg-slate-800"
        >
          <ClipboardPaste className="h-4 w-4" /> Paste from clipboard
        </button>
      </div>

      {notice && (
        <p className="mt-3 flex items-start gap-2 text-xs font-medium leading-relaxed text-amber-300">
          <AlertTriangle className="mt-0.5 h-4 w-4 shrink-0" />
          {notice}
        </p>
      )}

      {addr && !addrValid && (
        <p className="mt-3 flex items-center gap-2 text-xs font-medium text-rose-300">
          <AlertTriangle className="h-4 w-4 shrink-0" />
          That isn't a valid EVM address — it should be 42 characters starting with 0x.
        </p>
      )}
      {addr && addrValid && checksumBad && (
        <p className="mt-3 flex items-center gap-2 text-xs font-medium text-amber-300">
          <AlertTriangle className="h-4 w-4 shrink-0" />
          EIP-55 checksum mismatch — a character may be wrong. Re-copy the address from your wallet.
        </p>
      )}
      {addr && addrValid && !checksumBad && (
        <p className="mt-3 flex items-center gap-2 text-xs font-medium text-emerald-300">
          <ShieldCheck className="h-4 w-4 shrink-0" />
          Address verified.
        </p>
      )}
    </div>
  );
}
```

```js
// STBLSS Service Worker — lightweight, stateless frontend cache.
// Caches the app shell (HTML, JS, CSS, SVG icons) so the app loads
// instantly on mobile networks and works offline. Never caches
// blockchain RPC responses or user URL parameters — those are fetched
// live every time. No backend, no tracking.
// Bump CACHE when static shell assets (manifest, icons, index.html)
// change so old cached copies are purged on activate.
const CACHE = "stblss-v18";
const SHELL = [
  "/",
  "/index.html",
  "/manifest.json",
  "/stblss-icon.svg",
];

self.addEventListener("install", (event) => {
  event.waitUntil(
    caches.open(CACHE).then((cache) => cache.addAll(SHELL)).then(() => self.skipWaiting())
  );
});

self.addEventListener("activate", (event) => {
  event.waitUntil(
    caches.keys().then((keys) =>
      Promise.all(keys.filter((k) => k !== CACHE).map((k) => caches.delete(k)))
    ).then(() => self.clients.claim())
  );
});

// Stale-while-revalidate for same-origin GET requests only.
// URL query strings (invoice params) are never cached — each
// checkout link loads fresh from the network.
self.addEventListener("fetch", (event) => {
  const req = event.request;
  if (req.method !== "GET") return;
  const url = new URL(req.url);
  if (url.origin !== self.location.origin) return; // never cache cross-origin RPC
  if (url.search && url.pathname === "/checkout") {
    // Preserve stateless invoice links — always network-first, never cached.
    event.respondWith(fetch(req));
    return;
  }
  event.respondWith(
    caches.match(req).then((cached) => {
      const network = fetch(req)
        .then((res) => {
          if (res && res.status === 200 && res.type === "basic") {
            const copy = res.clone();
            caches.open(CACHE).then((cache) => cache.put(req, copy));
          }
          return res;
        })
        .catch(() => cached);
      return cached || network;
    })
  );
});
```

```jsx
// PWA install prompt — exposes the browser's native install flow via a
// persistent header button. The installed PWA launches at the exact URL
// the user was on (including all ?to=&net=&... invoice params), so
// stateless checkout links survive the install flow.
//
// Not every browser fires `beforeinstallprompt` (iOS browsers never do —
// Chrome on iOS is WebKit under the hood, same as Safari; desktop/Android
// Chrome only fires it once its criteria are met). The button always
// appears; on tap it triggers the native dialog when available, otherwise
// it surfaces clear, OS-specific "Add to Home Screen" steps so the user is
// never left with a dead button.
const UA = navigator.userAgent || "";

const isIOS = () =>
  /iphone|ipad|ipod/i.test(UA) ||
  // iPadOS 13+ reports as "Macintosh" by default — detect touch-capable Mac.
  (/macintosh/i.test(UA) && (navigator.maxTouchPoints || 0) > 0);

// Desktop vs mobile — purely client-side UA detection, no backend.
const isMobile = () => /android|iphone|ipad|ipod|mobile/i.test(UA);

// Identify the actual browser so the manual steps name the correct menu icon
// instead of assuming Chrome on every device.
const detectBrowser = () => {
  if (/OPR\/|Opera/.test(UA)) return "opera";
  if (/Edg\//.test(UA)) return "edge";
  if (/SamsungBrowser/.test(UA)) return "samsung";
  if (/Firefox\//.test(UA)) return "firefox";
  if (/Chrome\//.test(UA)) return "chrome";
  return "other";
};

  opera: { menu: "Opera's O menu (the round O icon in the top corner)", final: "Install" },

  samsung: { menu: "Samsung Internet's menu (the ≡ icon)", final: "Add to Home screen" },

  other: { menu: "your browser's menu", final: "Add to Home screen / Install app" },

  );
```

## Notes

- The `App.jsx` is a plain router with two public routes (`/`, `/checkout`) with no auth, no query client, and no toaster (none are used by STBLSS).
- The `package.json` includes the 6 runtime dependencies STBLSS actually needs: `react`, `react-dom`, `react-router-dom`, `framer-motion`, `lucide-react`, and `js-sha3` (used by the EIP-55 checksum).
- The fee wallet address is hardcoded in `src/lib/stblss.js` and displayed on the checkout page for transparency.
- A stateless "Print or Save Receipt" button appears on the checkout page once a payment is confirmed on-chain. It fires `window.print()` and a `@media print` block in `src/index.css` hides the live UI and renders only a clean black-and-white receipt (`#stblss-receipt`) with the brand, total due, token, network, recipient, and Status: Paid. No backend, no storage — the printed/saved PDF is the only durable record.
- STBLSS is a Progressive Web App. `public/manifest.json` declares the app with a `standalone` display, a generated 512×512 emerald "S" PNG (hosted on the Base44 media CDN) as the primary icon for both `any` and `maskable`, with the same-origin `public/stblss-icon.svg` STBLSS monogram as a fallback so Chrome still treats the app as installable and shows the native Install button even if the cross-origin PNG is filtered, and a `#1e293b` slate-blue theme. `index.html` points the favicon and apple-touch-icon at the same CDN PNG. `public/sw.js` (cache `stblss-v18`) is a lightweight service worker that caches the app shell (HTML, JS, CSS, same-origin SVG icon) so the app loads instantly and works offline on mobile networks — it never caches blockchain RPC responses or the cross-origin CDN icon, and any `/checkout?…` URL with invoice params is always fetched live from the network so stateless links are never served from stale cache. `src/components/InstallPrompt.jsx` exposes the browser's native install flow via a persistent "Install App" header button on the Generator and Checkout pages (the transient on-load mobile banner was removed in favor of the always-available button). Tapping the button triggers the native one-tap Add-to-Home-Screen dialog when the browser offers it; for browsers that don't fire `beforeinstallprompt` (iOS Safari never does, and Chrome only fires it once its install criteria are met), it instead shows clear, OS- and browser-specific "Add to Home Screen" steps (iOS Share-sheet, mobile Chrome/Edge/Samsung/Firefox/Opera menu, or desktop address-bar install icon) so the affordance is never a dead button. The installed PWA opens at the exact URL the user was on (query string included), so invoice links survive the install flow flawlessly. `src/main.jsx` registers the service worker on load as a progressive enhancement.
- The 512×512 brand PNG lives on the Base44 media CDN (`https://media.base44.com/images/public/6a69241a2e229db2030d9efb/25d5c289e_generated_image.png`); it is referenced directly from `index.html` (favicon + apple-touch-icon) and `public/manifest.json` (primary icon). For a fully self-contained fork, drop a local copy into `public/` (e.g. `public/logo-512.png`) and swap the two URLs to the same-origin path — the same-origin `public/stblss-icon.svg` fallback already keeps the app installable without it.
- Update the GitHub URL in `src/components/Footer.jsx` if your repo URL changes.

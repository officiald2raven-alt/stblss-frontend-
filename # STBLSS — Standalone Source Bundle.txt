# STBLSS — Standalone Source Bundle

This file contains the **complete, standalone source code** for STBLSS, stripped of all Base44 platform dependencies. It is a pure Vite + React + Tailwind CSS app that builds and runs anywhere — no backend, no database, no accounts.

## How to use this bundle

1. Download this file.
2. Create a new folder for your GitHub repo.
3. Create each file below at the exact path shown under the `=== FILE: path ===` headers.
4. Run `npm install` then `npm run dev` to run locally, or `npm run build` to deploy.
5. Push to GitHub.

=== FILE: README.md ===

````markdown
# STBLSS

An open-source, fully stateless, non-custodial stablecoin payment terminal.

STBLSS lets you generate anonymous stablecoin payment links and collect payments with an automated 99% recipient / 1% terminal fee split. There are no accounts, no server databases, and no tracking cookies. All transaction signing happens exclusively via your browser wallet.

## How it works

1. **Generate a link** — paste your 0x wallet address, pick a network and token, enter the amount.
2. **Share the link** — copy and send it to your payer through whatever channel you choose (email, DM, invoice, carrier pigeon).
3. **Collect instantly** — the payer opens the link, clicks Pay, and their wallet sends two ERC-20 transfers: 99% to you, 1% terminal fee.

STBLSS sends zero emails. You copy the link and send it yourself.

## What STBLSS does NOT do

- Does not hold, custody, or touch user funds at any point.
- Does not use accounts, passwords, or backend storage.
- Does not collect personal information, IP logs, or financial histories.
- Does not send emails or notifications.
- Is not a money transmitter — it is a client-side transaction composer UI.

All data lives entirely in the URL parameter text. The app compiles raw ERC-20 `transfer(address,uint256)` calls and hands them to your browser wallet to sign.

## Fee math (auditable)

```js
const fee = Math.round(total * 0.01 * 1e6) / 1e6;      // exactly 1% of the total
const payout = Math.round((total - fee) * 1e6) / 1e6;   // the remaining 99%
```

The platform fee wallet address is hardcoded in `src/lib/stblss.js` and visible in the source and on the checkout page.

## Supported networks

- Base (Layer 2)
- Arbitrum One (Layer 2)
- Ethereum Mainnet

## Supported tokens

- USDC
- USDT

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
```

## Privacy

STBLSS is completely stateless. We do not use accounts or backend databases. We collect zero personal information. Your data lives entirely inside your unique URL parameter text.

## Legal Disclaimer

STBLSS is a non-custodial software user interface utility. We do not process transactions, custody, or manage user funds. All transaction signing and execution happen exclusively via your independent browser wallet. Use at your own risk.
````

// PUBLIC, VERIFIABLE FEE MATH — anyone inspecting this file can audit the split.
// Total "Amount Due" is split into exactly two transfers and nothing goes anywhere else:
//   - 99%  → recipient's wallet (payout)
//   -  1%  → platform's hardcoded fee wallet (fee)
//   -  0%  → any other address
export function splitAmount(amount) {
  const total = Number(amount) || 0;        // the full Amount Due from the URL
  const fee = Math.round(total * 0.01 * 1e6) / 1e6;   // exactly 1% of the total
  const payout = Math.round((total - fee) * 1e6) / 1e6; // the remaining 99% (total − fee)
  return { total, fee, payout };
}

export function toUnits(amount, decimals) {
  const [whole, frac = ""] = String(amount).split(".");
  const padded = (frac + "0".repeat(decimals)).slice(0, decimals);
  return BigInt((whole || "0") + padded);
}

// ERC-20 transfer(address,uint256) calldata
export function encodeTransfer(to, units) {
  const addr = to.toLowerCase().replace("0x", "").padStart(64, "0");
  const amt = units.toString(16).padStart(64, "0");
  return "0xa9059cbb" + addr + amt;
}

export function formatAmount(value) {
  const n = Number(value);
  if (!isFinite(n)) return "0";
  return n.toLocaleString("en-US", { maximumFractionDigits: 6 });
}

export function shortAddress(addr = "") {
  if (addr.length < 14) return addr;
  return `${addr.slice(0, 8)}…${addr.slice(-6)}`;
}

// Strict format validation for an EVM address: must be 0x + exactly 40 hex chars.
// Catches the common paste/typing typos (wrong length, bad chars, missing prefix).
export function isEvmAddress(addr = "") {
  return /^0x[a-fA-F0-9]{40}$/.test(addr.trim());
}

export default function Generator() {

  const [link, setLink] = useState("");

  const set = (k) => (e) => setForm({ ...form, [k]: e.target.value });

  const generate = () => {
    const params = new URLSearchParams({
      to: form.to.trim(),
      net: form.net,
      token: form.token,
      amt: form.amt,

import React, { useState } from "react";
import { Loader2, Wallet, ShieldCheck } from "lucide-react";
import { NETWORKS, PLATFORM_FEE_WALLET, encodeTransfer, splitAmount, toUnits } from "@/lib/stblss";

// Poll a single transaction's receipt until mined; confirm success via status 0x1.
// Stateless: read through the payer's OWN wallet RPC (window.ethereum) — no backend.
async function awaitReceipt(eth, hash, { timeoutMs = 120000, intervalMs = 2500 } = {}) {
  const start = Date.now();
  while (Date.now() - start < timeoutMs) {
    let receipt = null;
    try {
      receipt = await eth.request({ method: "eth_getTransactionReceipt", params: [hash] });
    } catch { /* transient RPC — keep polling */ }
    if (receipt) return { confirmed: Number(receipt.status) === 1, receipt };
    await new Promise((r) => setTimeout(r, intervalMs));
  }
  return { confirmed: false, receipt: null };
}

// Poll an EIP-5792 batch (wallet_sendCalls) via wallet_getCallsStatus until the
// wallet reports CONFIRMED or FAILED. Verify per-call receipts when available.
async function awaitCallsStatus(eth, id, { timeoutMs = 120000, intervalMs = 2500 } = {}) {
  const start = Date.now();
  while (Date.now() - start < timeoutMs) {
    let res = null;
    try {
      res = await eth.request({ method: "wallet_getCallsStatus", params: [id] });
    } catch { /* transient — keep polling */ }
    if (res) {
      const status = String(res.status || "").toUpperCase();
      if (status === "CONFIRMED") {
        const receipts = Array.isArray(res.receipts) ? res.receipts : [];
        // If the wallet returned per-call receipts, verify each succeeded (0x1).
        // If it only returned CONFIRMED with no receipts, accept the wallet's word.
        return { confirmed: receipts.length ? receipts.every((r) => Number(r.status) === 1) : true };
      }
      if (status === "FAILED") return { confirmed: false };
    }
    await new Promise((r) => setTimeout(r, intervalMs));
  }
  return { confirmed: false };
}

// Wallet error codes meaning "the user declined the popup" — never auto-retry.
const USER_REJECTED = new Set([4001, -32001]);

export default function PayButton({ to, netKey, token, amount, onPaid }) {
  const [status, setStatus] = useState("idle"); // idle | working | confirming | paid
  const [error, setError] = useState("");
  const [flow, setFlow] = useState(null); // "batched" | "per-call" — shown for transparency

  const net = NETWORKS[netKey];

  const pay = async () => {
    setError("");
    const eth = window.ethereum;
    if (!net?.evm) {
      setError("Unsupported network. Open a valid STBLSS payment link and try again.");
      return;
    }
    if (!eth) {
      setError("No browser wallet detected. Install a wallet extension such as MetaMask to continue.");
      return;
    }

    setStatus("working");
    try {
      const accounts = await eth.request({ method: "eth_requestAccounts" });
      const from = accounts[0];

      try {
        await eth.request({ method: "wallet_switchEthereumChain", params: [{ chainId: net.chainIdHex }] });
      } catch (switchErr) {
        if (switchErr.code === 4902) {
          await eth.request({ method: "wallet_addEthereumChain", params: [net.params] });
        } else {
          throw switchErr;
        }
      }

      // --- NON-CUSTODIAL TRANSFER BUILD ---
      // We only compile raw ERC-20 `transfer(address,uint256)` payloads and hand them
      // to the user's LOCAL browser wallet (window.ethereum) to sign and broadcast.
      // No platform smart contract, relayer, or custodial layer is ever involved.
      const tokenInfo = net.tokens[token];
      const { fee, payout } = splitAmount(amount); // 99% payout, 1% fee, 0% elsewhere

      const calls = [
        { to: tokenInfo.address, data: encodeTransfer(to, toUnits(payout, tokenInfo.decimals)) },                 // 99% → recipient
        { to: tokenInfo.address, data: encodeTransfer(PLATFORM_FEE_WALLET, toUnits(fee, tokenInfo.decimals)) }, //  1% → fee wallet
      ];

      setStatus("confirming");

      let confirmed = false;
      let batchedAttempted = false;

      // --- PREFERRED: EIP-5792 batched send (ONE signature, verified on-chain) ---
      // The wallet signs both transfers at once; we then poll its calls-status
      // until CONFIRMED and check every receipt. Fully stateless — reads only
      // through the payer's own wallet RPC.
      // SAFETY: once we invoke wallet_sendCalls, if it throws a non-rejected
      // error we cannot know whether the wallet already submitted on-chain.
      // To prevent a double-send, we never fall through to per-call after a
      // batch has been attempted — except when the wallet clearly doesn't
      // support the method (method-not-found, code -32601).
      try {
        const callsId = await eth.request({
          method: "wallet_sendCalls",
          params: [{ version: "1.0", chainId: net.chainIdHex, from, calls }],
        });
        if (callsId) {
          batchedAttempted = true;
          setFlow("batched");
          const res = await awaitCallsStatus(eth, callsId);
          confirmed = res.confirmed;
        }
      } catch (batchErr) {
        // User declined the single-signature popup → stop, don't pester with a second.
        if (USER_REJECTED.has(batchErr?.code)) throw batchErr;
        if (batchErr?.code === -32601) {
          // Method not found — wallet doesn't support EIP-5792. Safe to fall back.
        } else {
          // Ambiguous: the wallet may have already submitted on-chain.
          // Do NOT fall through to per-call — that would double-send.
          setStatus("idle");
          setError("The batched payment couldn't be confirmed. Check your wallet or block explorer — no double charge was made.");
          return;
        }
      }

      // --- FALLBACK: per-call send (universal) + receipt verification ---
      // Every wallet supports this; we get a hash for each transfer and confirm
      // each against a mined receipt. Two approvals, but verified everywhere.
      // Only runs if batching was never submitted (no double-send after a batch).
      if (!confirmed && !batchedAttempted) {
        setFlow("per-call");
        const hashes = [];
        for (const call of calls) {
          const hash = await eth.request({ method: "eth_sendTransaction", params: [{ from, to: call.to, data: call.data }] });
          if (hash) hashes.push(hash);
        }
        let allOk = true;
        for (const hash of hashes) {
          const { confirmed: ok } = await awaitReceipt(eth, hash);
          if (!ok) { allOk = false; break; }
        }
        confirmed = allOk;
      }

      if (confirmed) {
        setStatus("paid");
        onPaid?.();
      } else {
        setStatus("idle");
        setError("A transfer did not confirm on-chain in time. Check your wallet or block explorer — your funds are safe and no custodial step was ever involved.");
      }
    } catch (e) {
      setStatus("idle");
      setError(e?.message || "Transaction was not completed.");
    }
  };

  const label =
    status === "working" ? "Awaiting Wallet Confirmation…" :
    status === "confirming" ? "Confirming on-chain…" :
    "Connect Wallet & Pay Now";

  return (
    <div>
      <button
        onClick={pay}
        disabled={status === "working" || status === "confirming"}
        className="flex w-full items-center justify-center gap-2 rounded-2xl bg-emerald-400 px-6 py-4 text-base font-bold text-slate-950 shadow-[0_0_40px_-12px_rgba(52,211,153,0.7)] transition-all duration-300 hover:bg-emerald-300 disabled:opacity-60"
      >
        {status === "working" || status === "confirming" ? <Loader2 className="h-5 w-5 animate-spin" /> : <Wallet className="h-5 w-5" />}
        {label}
      </button>
      {status === "confirming" && (
        <p className="mt-3 flex items-center justify-center gap-1.5 text-xs font-medium text-slate-400">
          <ShieldCheck className="h-4 w-4 text-emerald-400" />
          {flow === "batched"
            ? "Verifying your single batched payment on-chain — both transfers confirmed in one block."
            : "Verifying each transfer on-chain — every leg is confirmed, never assumed."}
        </p>
      )}
      {error && <p className="mt-3 text-sm text-rose-400">{error}</p>}
    </div>
  );
}

import React, { useState } from "react";

// Stateless, pointer-driven tooltip.
// Desktop: hover to reveal, move away to dismiss.
// Mobile: touch-and-hold to reveal, release / move finger to dismiss.
export default function InfoTooltip({ text }) {
  const [open, setOpen] = useState(false);

  return (
    <span className="relative inline-flex align-middle">
      <button
        type="button"
        aria-label="More info"
        tabIndex={0}
        onClick={(e) => e.preventDefault()}
        onPointerEnter={() => setOpen(true)}
        onPointerLeave={() => setOpen(false)}
        onPointerDown={() => setOpen(true)}
        onPointerUp={() => setOpen(false)}
        onPointerCancel={() => setOpen(false)}
        onBlur={() => setOpen(false)}
        className="ml-1.5 inline-flex h-[18px] w-[18px] select-none items-center justify-center rounded-full border border-slate-600 text-[11px] font-bold leading-none text-slate-400 transition-colors hover:border-emerald-400 hover:text-emerald-300 focus:outline-none focus-visible:ring-2 focus-visible:ring-emerald-400/40"
      >
        ?
      </button>
      <span
        role="tooltip"
        className={`pointer-events-none absolute bottom-full left-0 z-50 mb-2 w-60 max-w-[80vw] origin-bottom-left rounded-xl border border-slate-700 bg-slate-900 px-4 py-3 text-xs font-medium leading-relaxed text-slate-100 shadow-2xl transition-all duration-200 ease-out ${
          open
            ? "translate-y-0 opacity-100"
            : "pointer-events-none translate-y-1 opacity-0"
        }`}
      >
        {text}
      </span>
    </span>
  );
}

import React, { useState } from "react";
import { Check, Copy } from "lucide-react";

export default function CopyButton({ value, label = "Copy Link", className = "" }) {
  const [copied, setCopied] = useState(false);

  const copy = async () => {
    await navigator.clipboard.writeText(value);
    setCopied(true);
    setTimeout(() => setCopied(false), 1600);
  };

  return (
    <button
      type="button"
      onClick={copy}
      className={`inline-flex items-center gap-2 rounded-xl border px-4 py-2.5 text-sm font-medium transition-all duration-300 ${
        copied
          ? "border-emerald-400/60 bg-emerald-400/10 text-emerald-300"
          : "border-slate-700 bg-slate-800/60 text-slate-200 hover:border-slate-500 hover:bg-slate-800"
      } ${className}`}
    >
      {copied ? <Check className="h-4 w-4" /> : <Copy className="h-4 w-4" />}
      {copied ? "Copied!" : label}
    </button>
  );
}

## Notes

- This standalone version removes all Base44 platform dependencies (`@base44/sdk`, `@base44/vite-plugin`, AuthContext, etc.) since STBLSS doesn't use them for anything functional.
- The `App.jsx` is simplified to just a router with two public routes — no auth, no query client, no toaster (none are used by STBLSS).
- The `package.json` includes only the 5 runtime dependencies STBLSS actually needs: `react`, `react-dom`, `react-router-dom`, `framer-motion`, `lucide-react`.
- The fee wallet address is hardcoded in `src/lib/stblss.js` and displayed on the checkout page for transparency.
- Update the GitHub URL in `src/components/Footer.jsx` if your repo URL changes.
